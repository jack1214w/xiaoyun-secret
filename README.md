# 藏在小芸心中的秘密

《人際放大鏡》的延伸遊戲。這是給國小高年級的社會情緒學習（SEL）走路探索遊戲，互動模式參考〈校園溫度計〉。

這一週，小芸一次都沒有笑過。玩家扮演她的朋友，在校園裡度過一天：觀察她、在下課時去找知道內情的人，最後在放學的樓梯間，試著讓她重新笑出來。

## 遊玩

用瀏覽器直接開啟 `index.html`，不需要安裝任何東西。沒有網路也能玩，只是手寫字體會換成電腦內建的字型。

- 走路：手指在畫面上拖曳（會出現虛擬搖桿），或用鍵盤方向鍵、WASD。
- 遇到人會跳出紙條，用滑鼠點選，或按 1–4 選擇。
- 右上角的「線索」可以隨時查看線索筆記，「暫停」（或按 P）可以暫停。
- 開始頁可以調整紙條倒數：關閉、15、20、30 秒。

## 小芸這個角色

| | |
|---|---|
| 大家看到的 | 認真負責的模範生 |
| 她真正在意的 | 不完美也被接納 |
| 這次發生的事 | 她偷偷報名演講比賽，每天中午在樓梯間練習。週一的班內選拔，她講到一半忘詞，停了快 20 秒，還聽到後面有人說「欸，她也會忘詞喔？」。 |
| 她為什麼不開心 | 她難過的不是忘詞，而是怕大家發現她「其實沒有那麼厲害」。 |
| 雷區 | 「你很棒」、「下次一定會得名」、「才忘詞而已」。這些話都在提醒她：你不能出錯。 |
| 讓她開心的方法 | 先陪著、不逼問，再讓她知道你看見了她的努力，最後說出你自己的失敗。 |

## 遊戲機制

**一天八個時段**：到校 → 下課 → 國語課 → 午餐 → 打掃 → 下課 → 綜合課 → 放學。

**小芸的心門（隱藏數值）**：從 15 開始。每個選擇都會讓心門開一點或關一點。玩家看不到數字，但能看到三個變化：

- 校園的顏色會從灰色慢慢變暖。
- 地圖上小芸的嘴角會跟著改變。
- 每次選完，會看到「小芸心裡想」。

**六種選項**（沿用〈校園溫度計〉的分類）：看見、剛好、沒看清楚、做表面、路過、傷人。「逗她笑」、「買冰給她吃」都屬於做表面：可以化解尷尬，卻碰不到她的心事。

**同一張紙條，兩種線索**：每張紙條會隨機出現 A 或 B 兩種情境描述。同一句話在不同情境下，效果可能不一樣，所以玩家要先觀察，再回應。

**線索（5 條）**：只有兩次下課，每次 10 分鐘，時間不夠找所有人，玩家要決定先去找誰。問話的方式也有影響：

- 小禾要安靜陪著等她，她才會說。
- 阿翔的消息最快，但跟著起鬨會讓八卦傳得更遠，小芸的心門也會關上一點。

**放學的樓梯間**：連續四張紙條，依序是陪伴、看見、說出你自己的失敗、那張報名表。最有力的選項要先找到線索才會出現，例如「我知道你中午都在這裡練習」需要「樓梯間的練習」這條線索。

**四種結局**：

| 心門 | 結局 |
|---|---|
| 80 以上 | 她笑了 |
| 58 以上 | 她微微笑了 |
| 35 以上 | 她願意開口了 |
| 35 以下 | 心門還關著 |

把揉皺的講稿還給她，最好的結局會多一段後記，呼應《人際放大鏡》裡小芸那一章的結局。

**結算頁**：
- 揭曉小芸的秘密。
- 列出找到與沒找到的線索。
- 對照玩家在綜合課的猜測和真正的原因。
- 回顧一整天的選擇。
- 兩則補充說明、四題討論題。

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html` | 遊戲本體，單一檔案。前半段是「劇本設定區」，後半段是引擎。 |
| `劇本.md` | 完整劇本：所有紙條、選項、結果、小芸心裡想、線索與結局。由 `index.html` 自動產生，方便閱讀與討論。 |
| `tools/產生劇本.js` | 重新產生 `劇本.md` 的小工具。 |

## 修改劇本

所有文字都在 `index.html` 最前面的 `<script>` 區塊（劇本設定區），檔案裡有註解說明每個欄位的寫法，引擎的部分不用動。改完之後，可以用下面的指令更新 `劇本.md`（需要安裝 Node.js）：

```bash
node tools/產生劇本.js index.html 劇本.md
```

## 技術

單一 HTML 檔案，沒有相依套件與建置流程，也不蒐集任何使用者資料。地圖用 canvas 繪製；瀏覽器只記住「紙條倒數」的設定。字體使用 Google Fonts 的霞鶩文楷。引擎是重新撰寫的，沒有使用〈校園溫度計〉的程式碼。
